`electron-menubar` is continuously tested on macOS, Windows, and a range of Linux desktop environments. The tables below list the platforms where it is known to work.

## End-to-end tests

_Continuously verified by [E2E smoke tests](https://github.com/gitify-app/electron-menubar/blob/main/.github/workflows/e2e.yml)._

| Platform | Status |
| --- | --- |
| macOS 14 (Sonoma) | ✅ Pass |
| macOS 15 (Sequoia) | ✅ Pass |
| macOS 26 (Tahoe) | ✅ Pass |
| Ubuntu 22.04 | ✅ Pass |
| Ubuntu 24.04 | ✅ Pass |
| Ubuntu 26.04 | ✅ Pass |
| Windows Server 2022 | ✅ Pass |
| Windows Server 2025 | ✅ Pass |

## Visual tray rendering

_Continuously verified by [visual tray rendering tests](https://github.com/gitify-app/electron-menubar/blob/main/.github/workflows/visual-tray.yml). Each run boots the menubar fixture, screenshots the OS panel, and asserts both the tray icon and the popover window are painted. These checks confirm rendering, not tray-anchored placement. See [Window positioning on Linux](/platforms/linux-window-positioning)._
